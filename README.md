# RGD 소입자 산란 시뮬레이션 — 1단계: 물리 코어 + 검증

파장이 입자 크기보다 훨씬 긴 영역(레일리 산란)과 파장이 입자 크기와 비슷한 영역(회절) 사이의
경계를, RGD(Rayleigh–Gans–Debye) 근사로 수치적으로 정하는 논문용 시뮬레이션의 물리 코어.
통합 변수는 λ/a(파장 대 입자 반지름의 비). **이 단계에서는 UI를 만들지 않는다.**

전체 설계 결정은 [`DESIGN.md`](./DESIGN.md)에 기록되어 있다. 이 파일은 그 요약이다.

## 실행 방법

```
node verify.js
```

`physics.js`는 순수 계산 함수만 담고 있어 `require`(Node) 또는 `<script src>`(브라우저)로
그대로 재사용할 수 있다. `verify.js`는 Node 전용(fs/process 사용)이며, sweep을 먼저 계산한
뒤 검증 8항목을 실행하고, **전부 PASS일 때만** `verify-results.json`/`sweep.csv`를 기록한다.
하나라도 FAIL이면 파일을 쓰지 않고 종료 코드 1로 끝난다.

## 물리 모형 요약

- 입사파는 +z 방향 진행, 전기장은 x축 편광, 시간 규약 `e^{-iωt}`
- 산란체: 반지름 `a`인 구를 정육면체 격자(셀 중심 배치)로 채운 점 쌍극자 배열. **a = 1 고정**,
  **λ가 조작 변인**(a=1이므로 λ 값이 곧 λ/a). 크기 매개변수 `x = ka = 2π/λ`
- 총 분극률 `α_total = 1` 고정, 개별 쌍극자 `α = α_total/N` — N이 λ에 따라 바뀌어도 총 분극률이
  격자 해상도에 오염되지 않도록 하기 위함
- 쌍극자: `p_j = α·E₀·x̂·exp(i k z_j)`. α를 x에 무관한 상수로 두는 근거는 ω≪ω₀ 영역에서
  복원력이 지배해 변위 진폭·분극률이 거의 일정하다는 물리적 가정 (분광학적 축이 아니라
  기하학적 축 2πa/λ만 다룬다)
- 원거리 산란: `dσ/dΩ ∝ sin²Θ·|F(q)|²`, `F(q) = Σ_j exp(i q·r_j)`, `q = k(ẑ − n̂)`
- 생산 경로(`sigma1D`)는 φ 적분을 해석적으로 처리한 1차원 적분:
  `σ = (8π/3)·k⁴·α_total²·G(x)`, `G(x) = (3/8)∫_{-1}^{1}(1+μ²)|F(μ)/N|²dμ`.
  `G(x)`가 이 시뮬레이션의 핵심 단일 지표이며, `G(0)=1`에서의 이탈량이 곧 레일리 근사의 붕괴 정도다

자세한 API 목록과 각 함수의 역할은 `DESIGN.md` §3을 참고.

### 상용 sweep(n_d=20)의 정확도 참고 (x=2.0, 탐색 범위 상한)

x=2.0은 이 시뮬레이션의 탐색 범위(x≤2) 상한이자 이산화 오차가 가장 크게 나타나는 지점이다.
`n_d=20`(상용 sweep이 쓰는 값) 기준 이 지점의 오차 크기는 다음과 같다:

- 형상 인자(검증 1) 절대 오차: 최대 약 0.27%
- 2D 대조(검증 5a, 등방성 가정의 순수 판정 오차): 약 0.028%
- φ=0/φ=45° 직접 진단(검증 5b, 격자 이방성): 약 0.127%

모두 0.5% 임계값 안쪽이며, 별도로 n_d를 올릴 필요는 없었다(모든 검증이 n_d=20에서 1회 실행으로
통과). 즉 x≤2 범위 전체에서 상용 sweep(n_d=20)의 σ 오차는 대략 이 수준(0.3% 이하)으로 추정할 수
있다.

## 모형의 한계

- **Born 근사**: 쌍극자 간 상호작용을 무시한다
- **RGD 적용 조건**: `|m−1| ≪ 1` 이고 `2x|m−1| ≪ 1`. 실제 규산염 성간 티끌은 m≈1.7이므로
  이 시뮬레이션은 **정량적으로는 맞지 않는다** — 목적은 정량적 예측이 아니라 경향과 기제의 확인
- 그림자 효과와 흡수가 없으므로 x ≳ 3에서는 물리적으로 신뢰할 수 없다. 기본 탐색 범위는
  `x ∈ [0.0063, 2]`로 제한한다
- 기하학적 축(2πa/λ)만 다루며, 분광학적 축(ω/ω₀)은 다루지 않는다
