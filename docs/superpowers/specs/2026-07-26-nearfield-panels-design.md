## 1. 패널 구성 (2행 × 3열)

| | 열1 | 열2 | 열3 |
|---|---|---|---|

## 2. physics.js 확장 — 완전한 쌍극자 근접장

### 2.1 공식 (Jackson 9.18, 원거리 근사 금지)

단위 x-편극 쌍극자(p̂ = x̂) 기준 커널. 항등식 `(R̂×p̂)×R̂ = p̂ − R̂(R̂·p̂)`로 전개하면 복사항/준정전기항이 명시적으로 분리된다:

```
E(R) = exp(ikR)/R · { k²[p̂ − R̂(R̂·p̂)]                    ← 복사항, k²에 비례
                      + [3R̂(R̂·p̂) − p̂]·(1/R² − ik/R) }    ← 준정전기항, k와 무관
```

- `R = r_obs − r_j`, `R̂ = R/|R|`
- 복사항(`k²/R`)은 파장이 길면(k→0) 사라진다 → 긴 파장에서 밖으로 복사가 안 나감(논문 결론 2-3 "준정전기적 해석")
- 준정전기항(`1/R²`, `1/R³`)은 k와 무관 → 파장이 아무리 길어도 안 사라짐. 이 구분이 §5 (C)/(B) 항별 토글의 근거.

### 2.2 신규 함수

| 함수 | 역할 | 비고 |
|---|---|---|
| `RGD.dipoleFieldKernel(dx, dy, dz, k)` | 위 커널. 복사항/준정전기항을 **분리된 필드**로 반환: `{ radiative: {ex,ey,ez}, quasistatic: {ex,ey,ez} }` (각 성분 `{re,im}`). 합쳐서 전체 장을 만드는 건 호출자 책임 | 순수 함수. `p̂=x̂`만 지원(이 시뮬레이션에서 유일하게 필요한 방향) |
| `RGD.scatteredFieldAt(obsPoint, grid, k, alphaTotal)` | 브루트포스 전체 합(대칭 최적화 없음). `p_j = (alphaTotal/N)·exp(ikz_j)`를 커널에 곱해 전체 grid.points에 대해 합산. `{ex,ey,ez}` (각 `{re,im}`) 반환 | `verify.js` 항목 7·8 전용. 임의의 3D 관측점 지원 |
| `RGD.scatteredFieldXZPlane(xObs, zObs, grid, k, alphaTotal, opts)` | UI 전용 최적화. `y>0`·`x>0` 쌍극자만 순회(4배 절감, §4 근거), `opts.term`으로 `'full'\|'radiative'\|'quasistatic'` 선택. `{ex, ez}` 반환(`ey`는 관측점이 xz평면 위에 있다는 전제로 항상 0, 함수 주석에 명시) | 이 함수만 x/y 대칭을 쓴다. `scatteredFieldAt`은 검증용이므로 그대로 둔다 |

`alpha` = `alphaTotal/N` (개별 분극률) — **`alphaTotal`을 그대로 커널에 곱하면 안 된다.** 세 함수 모두 주석에 이 구분을 명시한다(1단계의 "편광 인자 이중 계산 금지" 주석과 같은 성격의 방어적 주석).

### 2.3 x/y 대칭의 수학적 근거 (§4에서 이미 검증된 관계, 코드 주석에 그대로 인용)

단일 축 위 쌍극자에 대해 직접 전개하면:

```
E_x(−x_o, z_o) = +E_x(x_o, z_o)
E_z(−x_o, z_o) = −E_z(x_o, z_o)
```

y 대칭(기존 사용자 지시)과 결합하면 `x≥0, y>0` 사분면만 계산하고 나머지 3사분면은 부호 규칙으로 복원 — 4배 절감.

## 3. verify.js 항목 7·8

### 항목 7 — 원거리 한계 (복사항 검증)

- 관측 거리: `r = max(30a, 50/k)` — **`kr=30`만으로는 부족**. `λ/a=1000`이면 `k=0.001`, `kr=0.03`으로 오히려 준정전기 영역이 되어버리므로, `kr ≥ 50`을 강제하는 `50/k` 하한을 둔다.
- 비교식: `|E_sca|² 목표값 = (k²·(alphaTotal/N)/r)² · dSigmaDOmega(points, k, θ, φ)` — 개별 분극률(`alphaTotal/N`)을 써야 함(`alphaTotal` 그대로 쓰면 `N²`배, 약 1.8e7배 어긋남).
- 평가 지점: **x=2.0**과 **x=0.0063**(sweep 양 끝) 두 지점, 각각 θ 여러 값(φ=0, φ=90° 포함).
- 임계값: 1%.
- 사용 함수: `RGD.scatteredFieldAt` (브루트포스, 대칭 최적화 없는 경로 — 검증 대상 커널과 UI 최적화 경로가 분리되어 있어야 이 검증이 커널 자체를 검증하는 의미가 있음).

### 항목 8 — 정전기 극한 (준정전기항 검증, 신규)

- 항목 7은 복사항(`k²/R`)만 검증한다. `1/R²`, `1/R³` 항은 전혀 검증되지 않는데 (A)(B)(C) 패널의 존재 이유가 바로 이 항이므로 별도 검증이 필요하다.
- `kR = 1e-4`에서 `dipoleFieldKernel`의 `quasistatic` 출력이 순수 정전기 쌍극자장 `[3R̂(R̂·p̂) − p̂]/R³`로 수렴하는지 확인.
- 임계값: 상대 오차 < 1e-6.
- 항목 7(`kR≫1`)과 항목 8(`kR≪1`)이 양쪽 극한을 조여 중간 `1/R²` 항까지 사실상 검증한다.

**항목 7·8을 모두 통과해야 1행 UI 구현으로 넘어가고, 1행 UI가 끝나야 2행 재배치로 넘어간다** (사용자 지시 그대로).

## 5. 패널별 상세

### (A) 입사파

- 표시량: `Re(E_x)` 순간 스냅샷(t=0), diverging 컬러맵(빨강-파랑)
- **파장 눈금 막대(필수)**: "λ = _a" 양방향 화살표. 창(10a)보다 길면 화살표가 패널 밖으로 잘려나가게 그대로 둔다 — 그 잘림 자체가 "파장이 표시 범위보다 크다"는 메시지
- 자동 캡션(`λ/a ≳ 20`일 때만 표시): "파장이 표시 범위보다 커서 입사파가 균일하게 보입니다"

### (B) 산란파

- 표시량 토글: **[전체 장] / [복사항만] / [준정전기항만]** — `scatteredFieldXZPlane`의 `opts.term`을 그대로 노출
- 색스케일은 (A)(C)와 공유(입사파 진폭=1 기준 고정)
- 산란파가 약해 안 보일 경우를 대비한 별도 "표시 배율" 토글, 배율값을 패널에 크게 표기

### (C) 중첩 결과 (입사파 + 산란파)

- 표시량: (A)+(B)의 [전체 장] 모드 합(항별 토글은 (B)만 적용 — (C)는 항상 전체 장)
- **고정 기준점 지표** (최댓값 대신 — 최댓값은 마스크 경계에서 나와 마스크 반경에 종속되므로 논문에 못 씀): `+z축, r=2a` 지점에서 두 수치를 나란히 표시
  - 준정전기(근접장) 비: `|E_sca(r=2a)|/|E_inc|` — λ와 무관하게 포화(사라지지 않는 성분)
  - 복사항 계수: `k²·α_total` — λ⁻²로 감소(사라지는 성분)
- 캡션: "파장이 길어지면 사라지는 것은 복사장이며, 입자 주변의 준정전기장은 남는다"
- 기준점(`r=2a`, +z축)을 화면에 명기

### (D) 내부 위상 지도

- `columns[{x,z,m}]` 산점도. 색 = `cos(k·z)`, 크기 = `m`. 기존 API 그대로 재사용, 신규 계산 없음

### (E) 위상자 합

- `exp(i q·r_j)`를 이어 붙인 누적합 경로(phasor walk). 전용 θ 슬라이더(전역 λ 슬라이더와 별개)
- **그리는 순서**: `q̂·r_j` 오름차순 정렬 후 연결(위상 단조 증가 → 나선 모양). `θ→0`에서는 `q=0`이라 방향 미정의이므로 이때는 `z_j` 순서로 대체
- 전체 스케일을 `N`으로 나눠 `|F|/N=1`이 고정 반지름 원이 되게 정규화

### (F) 산란 패턴

- `dSigmaDOmega` 극좌표, 편광면(`φ=0`)·수직면(`φ=90°`) 두 곡선
- (E)의 θ 슬라이더와 연동: θ 마커를 **수직면(`φ=90°`) 곡선 위**에 표시 — 그 곡선이 `|F(θ)|²` 그 자체(편광 인자=1)이므로 위상자 크기의 제곱과 직접 대응
- 캡션: "두 곡선의 차이는 쌍극자 복사의 편광 인자이며, 공통된 모양은 모두 위상자 합에서 온다"
