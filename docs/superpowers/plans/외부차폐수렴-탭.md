# 외부 차폐 수렴 탭 구현 계획
> 목적: 영상을 많이 늘리면 도파관 외부 전기장이 0으로 수렴함을 보인다.
> "도체 차폐 = 무한한 영상이 외부에서 입사파를 완전 상쇄"를 시각화.
> 기존 "무한 평행판" 탭은 절대 수정하지 않는다.

## 설계 메모

### 파일 구조
| 파일 | 역할 |
|------|------|
| `index.html` | 탭 버튼 2개, paneA(기존 래핑), paneB(새 탭) |
| `style.css` | `#s2Cv*` aspect-ratio 추가 |
| `shielding.js` | 외부 차폐 수렴 탭 전체 로직 |

### 기본값 (전파 모드)
- λ = 156 mm → 78 셀  
- a = 208 mm → 104 셀  
- 검증: λ (156mm) < 2a (416mm) → 전파 ✓  
- N 기본 10, 상한 1000

### 성능 전략
- **Hankel 테이블**: `recomputeFull` 시 N=1000 커버 테이블 한 번 생성  
  (λ=78셀, a=104셀 기준 ≈ 3.4MB, 빌드 ~수 ms)
- **증분 누적**: N 증가 시 새 영상 쌍만 `addOneSource`로 더함  
- **N 감소 시**: scattered 초기화 후 재계산

### ④ 외부 전기장 그래프
- 측정 띠: 도체판 바깥 5~30 셀 (위+아래 평균)
- 정규화: 도파관 내부 최대 |E| 기준
- 곡선 1: 현재 N의 외부 |E|(x) — 파란 실선
- 곡선 2: N=∞ 목표선 (0) — 노란 점선
- 가로축: ①②③ 패널과 동일 픽셀 정렬

### 탭 전환 로직
- paneA / paneB CSS display 토글
- `ShieldTab.activate()` — 첫 활성화 시 init + rAF 루프 시작
- `ShieldTab.deactivate()` — isActive=false → rAF 루프 자동 중단
